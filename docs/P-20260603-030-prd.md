# PRD: cultivation-simulator V268 梦境记忆系统 (Direction A)

## 1. 概述与目标

实现 **Dream Memory System（梦境记忆系统）**，为 NPC 提供跨会话记忆能力。参考 nanobot-design 的 Dream Memory 机制 + generic-agent-design 的 L0-L4 分层记忆思想。

**核心价值**：玩家与 NPC 的对话历史跨会话保留，NPC 可在后续相遇时引用"上次聊天的内容"。

## 2. 设计系统来源

| 设计系统 | Pattern | 落地 |
|---------|---------|------|
| nanobot-design | Dream Memory | 会话结束时自动归档对话到 IndexedDB |
| generic-agent-design | L0-L4 Memory | L0(瞬时)→L1(会话)→L2(天)→L3(永久) 四层压缩 |

## 3. 核心模块

### 3.1 DreamMemoryStore（梦境存储器）
- 基于 IndexedDB 持久化存储
- 存储结构：`{ npcId, playerId, timestamp, content, emotion, keywords }`
- 容量限制：每个 NPC 最多保留 100 条记忆，超出后触发 L2→L3 压缩

### 3.2 MemoryConsolidation（记忆整合）
- **L0 瞬时记忆**：当前会话内的对话缓存（内存）
- **L1 会话记忆**：会话结束时写入 IndexedDB（按 NPC 分组）
- **L2 天级记忆**：每日 00:00 触发压缩，相同关键词合并
- **L3 永久记忆**：手动标记重要的对话永久保留

### 3.3 DreamRecall（梦境回忆）
- NPC 见面时检查是否有 L1/L2/L3 记忆
- 有记忆时触发"似曾相识"提示，NPC 可引用最近一次对话内容
- 无记忆时正常初始化对话

### 3.4 NPCDreamBridge（NPC 集成）
- 集成到 `NPCDialogueService.js`
- 对话结束时调用 `DreamMemoryStore.archive()`
- 对话开始时调用 `DreamRecall.recall()`
